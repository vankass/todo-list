# 📝 ToDo List

🇬🇧 [English version](README.md)

Простое приложение для управления задачами.

Учебный проект, созданный для практики JavaScript и работы с браузерным хранилищем **LocalStorage**.

## 🚀 Особенности

* Добавление задач
* Удаление задач
* Отметка задач как выполненных
* Сохранение задач после перезагрузки страницы
* Фильтрация задач
* Поиск задач
* Переключение темы оформления

## 🛠 Технологии

* **HTML5**
* **CSS3**
* **SCSS**
* **JavaScript (ES6+)**
* **LocalStorage**
